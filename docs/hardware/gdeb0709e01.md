# GDEB0709E01 硬件规格与驱动要点

> 依据：官方《GDEB0709E01 产品规格书》与官方《GDEB0709E01-ESP32 程序示例》
> （资料存放于 `docs/vendor/gdeb0709e01/`）。

## 基本规格（来自规格书）

| 项目 | 参数 |
| --- | --- |
| 型号 | GDEB0709E01 |
| 显示技术 | E Ink Spectra 6（FPL Spectra6）彩色电子纸 |
| 显示尺寸 | 7.09 英寸，可视区 108(H)×144(V) mm |
| 分辨率 | **1200 × 1600**，282 dpi，像素间距 90 µm |
| 颜色 | 白 / 黑 / 红 / 黄 / 蓝 / 绿（6 色） |
| 驱动方式 | a-Si TFT 有源矩阵，COG 驱动 IC |
| 接口 | 模组 FPC 支持 4-wire SPI（BS1 引脚选择，见规格书 10.1） |
| 工作电压 | VDD 3.0V typ（2.4~3.6V），VGH/VGL 由模组内部升压 |
| 工作温度 | 0 ~ +50 ℃（存储 -25 ~ +60 ℃），刷新时间随温度变化 |
| 功耗 | 双稳态，仅刷新时耗电，刷新后不耗电维持画面 |

## 双 IC 拼接结构（官方示例实测）

屏幕由 **2 颗 E Ink 驱动 IC（GDEP133C02）** 拼接驱动：

- **CS0** 控制左半屏（600 像素宽），**CS1** 控制右半屏（600 像素宽）
- 电源类命令（PWR / EN_BUF / BTST / BOOST / BUCK / TFT_VCOM）只写给 **CS0**（主 IC），从 IC 跟随
- 参数类命令（CMD66 / PSR / CDI / TCON / AGID / PWS / CCSET / TRES）同时写给双 CS
- 个别命令（AN_TM）只写给 CS0

### 像素格式（关键）

- **每字节 2 像素（4 bit/像素）**，高 nibble 在前
- 颜色 nibble 编码：`BLACK=0x0, WHITE=0x1, YELLOW=0x2, RED=0x3, BLUE=0x5, GREEN=0x6`
- **整幅图 960000 字节** = 1200 × 1600 / 2
- **内存布局**：每行 600 字节 → 前 300 字节送 IC0（左半屏），后 300 字节送 IC1（右半屏）
- **行内像素从右到左排列**：`new_x = (1198 - x)`，`index = y*600 + new_x/2`（官方示例 draw_checkerboard 证实）

```
行 y 的内存（600 字节 = 1200 px @ 2px/byte）:
┌─────────────── 300 B ───────────────┬─────────────── 300 B ───────────────┐
│ IC0 左半屏 600px（像素从右到左）       │ IC1 右半屏 600px（像素从右到左）       │
└─────────────────────────────────────┴────────────────────────────────────┘
```

## 引脚定义（好视达配套 ESP32 开发板，官方示例 pindefine.h）

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| SPI_CS0 | GPIO 18 | 左半屏片选（手动 GPIO 控制） |
| SPI_CS1 | GPIO 17 | 右半屏片选（手动 GPIO 控制） |
| SPI_CLK | GPIO 9 | SPI 时钟（SPI3_HOST，10 MHz） |
| SPI_Data0 | GPIO 41 | MOSI |
| SPI_Data1 | GPIO 40 | 预留（当前驱动未用） |
| SPI_Data2 | GPIO 39 | 预留 |
| SPI_Data3 | GPIO 38 | 预留 |
| EPD_BUSY | GPIO 7 | 输入，忙指示（示例配置 NEGEDGE 中断） |
| EPD_RST | GPIO 6 | 复位，低有效 |
| LOAD_SW | GPIO 45 | 负载开关（上电后置高） |

> 官方示例使用 **SPI 8-bit 命令相位**（`trans.cmd`），CS 由 GPIO 手动拉低/拉高，
> 命令与数据都在同一 CS 周期内发送（无 D/C 引脚）。若自行接线（非配套板），
> 需要按 FPC 引脚与参考电路（规格书 9 章）重新映射。

## 初始化序列（官方 initEPD）

1. 硬件复位：RST 低 20ms → 高 20ms；`checkBusyHigh()` 等 BUSY 拉高
2. `AN_TM` (0x74) 只 CS0：`C0 1E 1E CE CE CE 15 15 55`
3. `CMD66` (0xF0) 双 CS：`49 55 13 5D 05 10`
4. `PSR`  (0x00) 双 CS：`DF 69`
5. `CDI`  (0x50) 双 CS：`F7`
6. `TCON` (0x60) 双 CS：`03 03`
7. `AGID` (0x86) 双 CS：`10`
8. `PWS`  (0xE3) 双 CS：`22`
9. `CCSET`(0xE0) 双 CS：`01`
10. `TRES` (0x61) 双 CS：`04 B0 03 20`
11. `PWR`  (0x01) 只 CS0：`0F 00 28 2C 28 38`
12. `EN_BUF`(0xB6) 只 CS0：`07`
13. `BTST_P`(0x06) 只 CS0：`E8 28`
14. `BOOST_VDDP_EN`(0xB7) 只 CS0：`01`
15. `BTST_N`(0x05) 只 CS0：`E8 28`
16. `BUCK_BOOST_VDDN`(0xB0) 只 CS0：`01`
17. `TFT_VCOM_POWER`(0xB1) 只 CS0：`02`

## 全屏刷图流程（官方 pic_display_test）

1. 关 CS；`setPinCs(0, LOW)` 选 IC0
2. `DTM` (0x10) → 逐行发送左半 300 字节/行（每行间延时 1ms）
3. `setPinCs(1, LOW)` 选 IC1
4. `DTM` (0x10) → 逐行发送右半 300 字节/行
5. 关 CS；**刷新** `epdDisplay()`：
   - `PON` (0x04) 双 CS，无数据 → `checkBusyHigh()`
   - 延时 30ms → `DRF` (0x12) 双 CS，数据 `01` → `checkBusyHigh()`
   - `POF` (0x02) 双 CS，数据 `00` → `checkBusyHigh()`

> 支持局部刷新（PTLW 0x83 + CMD66 前置），见官方 `partialWindowUpdate*`，
> 窗口约束：HRST 8 的倍数、HRED ≡ 3 (mod 8)、x 偏移 ≤584、宽 ≤600、y 偶数对齐。

## 状态读取

`0xF2` 读 3 字节，bit0 = 1 表示驱动 IC 就绪（`checkDriverICStatus`）。

## 注意事项

- 刷新时序依赖 BUSY 同步，勿在刷新过程中打断电源
- 彩色 E Ink 全刷较慢（秒级），适合低频更新场景
- 官方示例每行发送后延时 1ms 防止硬件过载，移植时保留
- 参考电路与 FPC 引脚见规格书 9 章（PDF 中为图）
