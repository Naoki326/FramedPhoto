# 色域外亮色的墨水对混色与浓彩偏置

校准（a10e6e6）把量化目标（targets）换成实测 device 色后，六种墨水都比
理想色板暗（唯一亮彩墨是黄 (247,247,17)，绿 G≤140、蓝 B≤184，白墨实测
(217,217,217)）。亮青/亮品红这类**色域外高饱和色**在「逐像素最近墨水」
判定下必然命中唯一的亮墨——白（RGB 与 OKLab 距离皆然，已实测），彩虹图
亮带青/品红色块白墨占比 83~85%、深带 95%，人眼即「混色不对、出现白色」。
历史上「OKLab 距离高饱和亮色误归白，回退 RGB」（a10e6e6）只是换了种
失败方式，未触及根因：任何最近墨水判定在色域外亮色上都会偏向白墨。

## 决定

1. **墨水凸包门控**：源像素在六墨凸包之外且饱和度 > 0.35 时，改用
   **墨水对混色**（纯墨吸附除外，见 4）；色域内亮饱和色仍走 6 墨涌现式
   FS 混色（实测平均保真更好，避免为修白块损失整图保真）。
   *修订*：初版还要求「最近墨水为黑/白」，真机验证发现色域外且最近墨水
   为彩色的暗饱和色（如暗黄绿 (26,128,0)→绿）同样会被自由 FS 漂移失稳
   抖出成团杂色斑块/条纹（彩虹图绿区红块、亮带竖纹），故门控不再区分
   最近墨水是否黑白。
2. **最小二乘墨水对**：在 21 个墨水对中取闭式 λ 解（mix = j + λ(i−j)），
   墨水对由**源像素**锚定（源色在色域内，色相稳定，不随误差漂移退化成
   黑白对），候选对必须含彩色墨水。
3. **沿轴一维抖动**：量化基准改为轴上虚拟源 v0 = a + λ_c_eff·(c−a)，
   误差只在轴上传播——1D FS 占空比精确实现 λ_c_eff，且垂直分量不发散。
   *修订*：FS 取墨与残差均基于限幅（[0,255]）后的值——曾尝试去掉 clamp
   让色域外反馈更充分，实测误差残差无界累积导致大面积平色区纹理失稳
   （暗黄绿区抖出黑/黄/红噪声团、条纹指标劣化），故恢复限幅；干预路径
   的虚拟基准本就在色域内，clamp 不影响其占空比收敛。
4. **纯墨吸附**：源色距某墨水 ≤30 RGB 单位（距离² ≤ 900）时直接纯色
   输出，不参混色——保护彩虹图底部六纯色参考块与照片中的纯色区域。
   彩虹图底部色块同步改画 device 观感色（吸附后屏上即纯墨真色）。
5. **浓彩偏置（chroma_bias，0..4）**：把目标彩色份额放大
   λ_c·(1 + bias·sat)，作为运行时可调项（runtime_config
   `chroma_bias`，管理台校准页滑杆），默认 0 = 忠实混色。1D 占空比
   机制下旋钮全色平滑单调（纯青 白58%→0%，粉彩青 87%→56%）；距离乘子
   方案因「λ→份额」映射因色而异且存在悬崖而被否决。

## Considered Options

- **换 OKLab 距离**（历史方案 a10e6e6 的反向）：被否决——纯青在 OKLab
  下最近墨水仍是白（彩色墨水 L≈0.62 vs 白 0.92，亮度差主导）；且亮青的
  最近**彩色**墨水是黄，色相更错。
- **硬性饱和度门控**（高饱和像素排除白/黑候选）：被否决——彩色墨水凸包
  无法企及亮青的 G=255，误差无解发散后锁死纯蓝；粉彩绿被黄墨带偏色相。
- **白墨距离软惩罚**（距离乘 (1+k·S²)）：被否决——k=0→白 95%、k=2→白
  0%，双稳态无中间态；且不同 λ 的颜色需要相差一个量级的乘子。
- **恢复理想色板做量化目标**（回退 a10e6e6 的 targets 改动）：被否决——
  损失「量化在屏幕显示色空间进行」的保真收益（金黄→黄红混色的初衷），
  且理想色板下天空等粉彩仍偏白。
- **蛇形扫描 / 有界漂移（±64/±32）**（修复条纹伪影的候选）：被否决——
  实测条纹非扫描方向性伪影（蛇形无效），限幅会打乱干预路径的占空比平衡
  （淡带绿区红墨反而 7.7%→10.3%）。

## Consequences

- 彩虹图三带无白色退化块、无成团杂色（外来墨成团率 14%→细抖动）、
  无列条纹（列翻转率 0%）；真照片池化残差持平或更好（73.9/14.3/5.2/5.8
  vs 基线 86.3/10.4/5.3/5.5）；彩虹图底部六纯色块画 device 色后纯度
  ≥97%。
- 干预方案按源色 8 级/通道分桶缓存（`_intervention_plan`）：干预开销
  从 8.5x（44s/张全图）降到 ~1.2x（6.2s）。
- oklab FS 分支（实验遗留）不含本修复；如启用需单独适配。
- 白墨校准采样偏暗（217 vs 255）会加重偏白，属校准照片曝光问题，
  重拍校准照片可改善，与本决策正交。
