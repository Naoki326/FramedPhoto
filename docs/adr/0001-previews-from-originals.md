# 预览从原图,不从 FPS6 帧还原

管理台预览的目的被确认为「辨认内容」,不是「模拟真机观感」;FPS6 帧是 6 色
有损量化,从中还原出的预览既非原图、也不服务于该目的。因此废除全部「回退
预览」路径(原图缺失时由帧渲染 PNG 的分支):预览永远由原图缩放而来,缺原图
返回 404、不做占位图;原图与 FPS6 帧同生同灭——天气卡片与自由模块生成时落盘
中间图(与帧同 stem、同批滚动清理),删除原图时帧一并删除。

## Considered Options

- **`from_fps6()` 收口 10 处回退预览 + 校准色板渲染**(2026-08-16 架构评审候选 2
  原方案):把「校准色板在回退路径丢失」定性为 bug 来修。被否决:它默认「有帧
  无原图」是合法状态,而该状态本身违反生命周期契约;「理想色 vs 校准色」之争
  也随路径废除而消失。
- **色板跟帧 / 色板跟设备**:仅当回退预览存在才有意义的问题,一并作废。

## Consequences

- `preview_png()` / `preview_png_landscape()` 保留,但唯一消费者是自由模块坏图
  自检(`_detect_tiling`,恒用理想色板,阈值按理想色校准)——不要把它「修复」
  成管理台预览。
- 帧头 `palette_version` 恒写 1,无人读取;语义见 `docs/protocol/fps6-format.md`
  (帧格式唯一人写权威)。
