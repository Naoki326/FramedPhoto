# 照片库本地化管理文件夹，NAS 全面退役

> 取代 ADR-0005 的「NAS 目录结构是唯一事实源」前提；0005 的内容哈希迁移
> 语义（移动 / 复制识别）继续有效。

照片库不再从 NAS 同步（pull），上传也不再推回 NAS 备份（push），内容库
归档到 NAS 的能力一并移除。照片库成为纯本地资产：照片经管理台上传到
所选文件夹，文件夹（即照片分类）可在管理台新建、重命名、删除空文件夹。

## Context

- NAS 同步链路（sync_nas.sh 拉取 + rsync 推回 + 内容库归档）运维成本高，
  用户不再需要 NAS 上的照片作为选片池。
- 家庭共享上传的「Frame_名字」隐式命名规则不直观，改为显式选文件夹。
- ADR-0005 禁止改名的原因是「与 rsync 镜像同步冲突」——同步没了，约束
  解除；但「分类 = 第一层文件夹、一照一分类、不打标」保持不变。

## Decision

- 照片上传：`POST /analysis/upload` 落盘 `PHOTO_LIB_DIR/<folder>/<relpath>`，
  目标文件夹不存在则自动创建；分类 = 文件夹名（语义不变）。
- 文件夹管理（`/analysis/folders`）：
  - 新建：合法名（中文/字母/数字/下划线/横线，不可叫「未分类」）即可，
    空文件夹即空分类 tab；
  - 重命名：目录 mv + 评分记录按路径段边界替换前缀并改写分类（评分文案
    保留，等价于一次显式「移动」迁移），时段绑定与手动精选路径联动改写；
  - 删除：仅允许空文件夹；该分类下残留的评分记录（文件已不在）一并
    清理，时段绑定置空（回全库）。
- 「未分类」是保留分类（根目录散照 / 内容库上传图），不对应任何文件夹，
  不可新建、重命名或删除。
- 内容库「同步到 NAS / 删除本地副本」端点退役；删除内容库图片时连带
  清理其评分记录与「推送到显示」绑定（原图与帧同生同灭的推论）。

## Consequences

- ADR-0005 的镜像前提失效，但其哈希迁移语义（migrate_or_record）保留：
  用户在 Finder 手动移动 / 复制照片后重新分析，评分文案仍随内容迁移。
- 重命名文件夹等价于批量「移动」：同分类所有记录的 path 前缀替换、
  分类改写，无需重新分析；preview_cache 以路径+mtime 为键，旧缓存自然
  失效成孤儿，不主动清理（无害）。
- 删除文件夹必须先清空照片——刻意不做「连照片一起删」，空文件夹操作
  可安全重试、不会误删 3GB 资产。
- NAS 相关配置项（NAS_SSH_* / NAS_PHOTO_DIR 等）、sync 路由与
  sync_nas 定时任务全部移除；升级时需卸载 launchd 的 nas-sync 任务。
