# FPS6 设备格式协议（v1）

> **本文是 FPS6 帧格式的唯一人写权威。** 帧格式的任何改动只改本文一处；
> 服务端实现（`services/app/epd_image.py` 的打包/解析）与固件常量
> （`firmware/main/fps6_format.h`）均以本文为准，不得另立副本。

FramedPhoto 服务端与设备端之间的图片交换格式，与 GDEB0709E01 驱动布局一一对应。

## 文件结构

```
偏移   长度   内容
0      4      magic "FPS6"
4      4      width  (u32 LE) = 1200
8      4      height (u32 LE) = 1600
12     1      format = 1（4bit 双 IC 布局）
13     1      palette_version = 1（恒为 1，保留字段：写入方恒写 1，读取方不解释、不校验）
14     6      reserved（置 0）
20     960000 数据区（1200*1600/2 字节）
```

## 帧校验（服务端 `parse_fps6`）

解析入口 `services/app/epd_image.py` 的 `parse_fps6(frame, expected_size=None)`：

- **magic 与长度必检**：magic 必须为 `"FPS6"`；整帧长度必须等于
  `20 + width*height/2` 字节（短于为截断，长于为长度不符；短于 20 字节头
  同样视为截断）。
- **尺寸校验可选**：调用方传 `expected_size` 时校验帧头 width/height 与之
  相等（上传场景传入，坏图自检等内部场景不传）。
- **format、palette_version、reserved 为保留字段**：解析不读取、不校验其值
  （`palette_version` 写入方恒写 1）。

固件侧（`firmware/main/content_client.c`）下载帧校验口径一致：先验 magic 与
宽高（1200x1600），坏帧零字节落分区、按下载失败重试。

## 数据区布局（format=1）

对应硬件：屏幕由 2 颗 GDEP133C02 驱动 IC 拼接（各 600 像素宽）。

```
一行（600 字节 = 1200 像素 @ 4bit/像素）:
┌────────────── 300 B ──────────────┬────────────── 300 B ──────────────┐
│ IC0（屏幕左半 x=0..599）          │ IC1（屏幕右半 x=600..1199）       │
│ 字节 k: 像素对 (2k, 2k+1)         │ 字节 k: 像素对 (600+2k, 601+2k)   │
└───────────────────────────────────┴──────────────────────────────────┘
```

- 每字节 2 像素：**高 nibble = 左像素**（x 更小的），低 nibble = x+1
- **行内像素从左到右**：字节 0 是屏幕最左的像素对（LTR）
- ⚠️ 早期版本按官方示例的 RTL（字节 0 = 最右像素对）打包，真机实测导致整图水平镜像；2026-08 已改 LTR 并验证正常
- 全帧数据 = 逐行拼接（y 从 0 到 1599，行号在 IC0/IC1 内部均从 0 开始）
- 设备端发送顺序：先 IC0 全部 1600 行（每行 300B），再 IC1 全部 1600 行（每行 300B）——见 `gdeb0709e01_display_image()`

## 颜色 nibble

| nibble | 颜色 | 近似 RGB |
| --- | --- | --- |
| 0x0 | 黑 | (0, 0, 0) |
| 0x1 | 白 | (255, 255, 255) |
| 0x2 | 黄 | (255, 150, 0) |
| 0x3 | 红 | (255, 34, 34) |
| 0x5 | 蓝 | (0, 70, 200) |
| 0x6 | 绿 | (0, 150, 60) |

> 无 0x4 编码。RGB 值仅为近似，实际以数据手册色域为准。

## 转换链路（服务端）

```
原始图片 → EXIF 摆正（手机照片）
         → 竖屏/方形图 cover 铺满 1200x1600；横屏图旋转 90° 后 cover 铺满（文字随照片一起旋转）
         → 6 色量化（Floyd–Steinberg 抖动）→ 行内左→右（LTR）+ 双 IC 拆分 → FPS6 数据区
```

实现：`services/app/epd_image.py`（`prepare_image` / `prepare_image_with_caption` / `preview_png`）。

> 横屏照片旋转 90° 铺满全屏（无黑边），底部文案/日期随照片一起旋转；
> 观看时把相框顺时针横放（顶部向右）即照片与文字均正立。

## 设备端对接

`firmware/components/gdey_epd/`：

- `gdeb0709e01_display_image(dev, frame, len)`：整帧刷入（逐行转发，不复制）
- `gdeb0709e01_begin / send_ic_row / next_ic / end`：流式接口（HTTP 边下边刷 / 图案生成用）

字节序注意：驱动以 `SPI 8-bit 命令相位` 发送，nibble 高位先出，与数据区编码一致，无需转换。
