## M4 — 打磨
- [ ] 低功耗（deep sleep 定时唤醒刷新）

## 硬件备件建议
- 烧录前核对引脚映射；电子纸刷新电流大，避免用开发板 USB 口带大负载时掉压。
- 准备第二块屏幕或排线时注意 FPC 方向，避免插反。
